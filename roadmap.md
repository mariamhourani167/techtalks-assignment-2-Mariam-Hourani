# Six-Month Learning Roadmap

## Month 1 — Web Fundamentals

### Learn
- HTML5
- CSS3
- Responsive design
- JavaScript fundamentals
- DOM
- HTTP basics
- Git and GitHub

### Build
A responsive personal portfolio website.

### Why
HTML, CSS, JavaScript, and Git are basic building blocks that appear repeatedly in the listings. I want these to be strong before moving into frameworks.

---

## Month 2 — React + TypeScript

### Learn
- React components
- Props and state
- Hooks
- Forms
- Routing
- API requests
- TypeScript
- Basic frontend testing

### Build
A React + TypeScript dashboard that consumes a public API.

### Why
React, Angular, Vue, JavaScript, and TypeScript appear frequently in the research. I will focus on React first rather than trying to learn every frontend framework.

---

## Month 3 — Backend + APIs

### Learn
- Node.js
- Express
- REST API design
- Authentication
- JWT
- Validation
- Error handling
- Backend architecture
- API security basics

### Build
A REST API for a study-management application.

### Why
API development was one of the strongest recurring requirements across the listings.

---

## Month 4 — SQL + Full-Stack Integration

### Learn
- PostgreSQL
- SQL
- Relationships
- Database schema design
- Indexes
- Queries
- ORM concepts
- Connecting frontend, backend, and database

### Build
Turn the Month 3 project into a complete full-stack application with:
- React frontend
- Node/Express backend
- PostgreSQL database
- Authentication

### Why
Database knowledge was another very consistent requirement.

---

## Month 5 — Professional Development

### Learn
- Testing
- Debugging
- Clean code
- Git workflows
- Docker
- CI/CD basics
- Cloud fundamentals
- Basic software architecture
- Performance and security

### Build
Improve the previous full-stack project:
- Add tests
- Dockerize it
- Add a basic CI/CD workflow
- Deploy it

### Why
Several listings ask for CI/CD, Docker, testing, cloud, and production experience.

---

## Month 6 — AI + Portfolio

### Learn
- AI coding assistants
- Reviewing AI-generated code
- Prompting for development tasks
- LLM API integration
- Security when using AI
- Deployment
- Technical interview preparation

### Build
Finish and polish the main portfolio projects.

### Final target
By the end of the six months, I want to have 2–3 projects that are complete enough to show to an employer, with:
- GitHub repositories
- Clear READMEs
- Screenshots
- Live demos where possible
- Good code structure
- Tests
- Documentation
