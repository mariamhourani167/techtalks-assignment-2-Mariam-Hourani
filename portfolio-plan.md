# Portfolio Plan

## Project 1 — AI Study Assistant

### Idea

A full-stack study platform where students can organize courses and use AI to help with studying.

### Features
- User registration and login
- Subjects and courses
- Upload study material
- AI-generated summaries
- Quizzes
- Flashcards
- Progress tracking
- Study planner
- AI question-and-answer assistant

### Technologies
- React
- TypeScript
- Node.js
- Express
- PostgreSQL
- REST APIs
- Authentication
- Git
- Docker
- LLM API

### Skills demonstrated
- Frontend development
- Backend development
- APIs
- Database design
- Authentication
- AI integration
- Deployment

### Why I chose it

This is a project I would genuinely use, so I think it will be easier to keep improving instead of making it only as a portfolio exercise.

## How These Projects Match the Research

The projects are intentionally different.

The first shows that I can combine full-stack development with AI.

The second shows common business application features such as authentication, databases, APIs, and CRUD operations.

The third gives me a chance to demonstrate data handling, dashboards, backend work, and deployment.

Together, they cover many of the skills that appeared repeatedly in the job listings.
