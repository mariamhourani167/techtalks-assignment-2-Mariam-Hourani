# Market Research

## 1. Chosen Niche

### Full-Stack Development

I chose Full-Stack Development because I want to understand how a complete application is built, not only the part that users see. I want to be comfortable working on the frontend, backend, APIs, and databases and eventually connect that knowledge with my interest in AI.

Before doing this research, I already had an idea of some technologies I wanted to learn. Looking at actual job listings helped me check whether those priorities match what employers are asking for.

I focused on full-stack and closely related software-engineering positions in Lebanon.

## 3. Pattern Analysis

After comparing the listings, I noticed that the exact technology stack changes from company to company, but the underlying skills are much more consistent.

### Most repeated areas

| Skill / Area | Finding | Priority |
|---|---|---|
| Full-stack/backend + frontend development | Appears throughout the sample | Very High |
| Databases / SQL | Appears throughout the sample | Very High |
| REST APIs / integrations | Appears throughout the sample | Very High |
| JavaScript / TypeScript | Appears in most listings | Very High |
| Frontend frameworks | React and/or Angular/Vue appear repeatedly | High |
| Git / source control | Repeated across listings | High |
| CI/CD | Repeated in several listings | Medium-High |
| Cloud / Docker | Appears in several listings | Medium |
| Testing | Appears in several listings | Medium-High |
| AI-assisted development | Especially visible in recent Aspire roles | Emerging |

### What I consider essential

Based on the sample, I would prioritize:

1. JavaScript and TypeScript
2. React or another major frontend framework
3. Backend development
4. REST API development
5. SQL and relational databases
6. Git
7. Authentication and security basics
8. Testing and debugging

### What I would learn after the basics

I would then add:

- Docker
- CI/CD
- Cloud platforms
- Microservices
- More advanced architecture
- NoSQL
- AI-assisted development

### What surprised me

The biggest thing I noticed is that employers are not all using the same stack. One job may use .NET and SQL Server, another may use Node.js and PostgreSQL, and another may use PHP/Laravel and Vue.

At first this made full-stack development seem like I would have to learn everything. After comparing the listings, I think the better approach is to learn the common concepts well and then specialize in one main stack.

I was also interested in seeing AI-assisted development mentioned directly in recent listings. It makes sense to me because AI can help developers move faster, but the listings still expect developers to understand the code and judge whether the AI-generated result is correct.

---

## 4. What I Will Prioritize

My main learning priorities will be:

**First:** JavaScript/TypeScript, React, HTML/CSS, Git  
**Second:** Node.js, Express, REST APIs, authentication  
**Third:** SQL, PostgreSQL, database design  
**Fourth:** Testing, Docker, CI/CD, cloud basics  
**Fifth:** AI-assisted development and AI integrations

I am choosing this order because it follows the common requirements in the listings instead of trying to learn every technology at the same time.
